
# 🍔 FoodConnect – Sistema Inteligente de Delivery e Gestão de Restaurantes

## 📖 Descrição
O **FoodConnect** é uma plataforma inteligente de delivery desenvolvida como projeto da disciplina **Pensamento Computacional** no curso de Engenharia de Software.

O sistema tem como objetivo conectar clientes, restaurantes e entregadores em uma única plataforma digital, oferecendo pedidos online, rastreamento em tempo real e recomendações inteligentes de refeições com base no perfil do usuário.

O projeto aplica conceitos de pensamento computacional, engenharia de software e desenvolvimento de sistemas de larga escala.

---

# 🎯 Objetivos

- Aplicar conceitos de pensamento computacional na construção de sistemas.
- Desenvolver uma aplicação escalável para múltiplos usuários.
- Utilizar decomposição, abstração e reconhecimento de padrões.
- Simular desafios reais de sistemas modernos de delivery.
- Aplicar metodologias ágeis durante o desenvolvimento.

# 🧠 Pensamento Computacional Aplicado

## 🔹 Decomposição

O sistema foi dividido em módulos menores:

- Autenticação de usuários
- Gestão de restaurantes
- Gestão de pedidos
- Rastreamento de entregas
- Sistema de recomendações
- Painel administrativo

---

## 🔹 Reconhecimento de Padrões

- Estrutura semelhante ao iFood e Uber Eats
- Sistema de login baseado em aplicações bancárias
- Interface inspirada em marketplaces modernos

---

## 🔹 Abstração

Foi criado um modelo simplificado utilizando diagramas UML para representar:

- Usuários
- Restaurantes
- Pedidos
- Entregadores
- Pagamentos
