# 🍔 FoodConnect – Organização de Dados

## 📖 Descrição

Este projeto foi desenvolvido para a atividade prática da disciplina Pensamento Computacional.

O objetivo é representar um mesmo conjunto de informações utilizando três estruturas computacionais diferentes:

- Lista
- Grafo
- Hierarquia

O tema escolhido foi o sistema de delivery FoodConnect.

---

# 🎯 Objetivos

- Aplicar conceitos de estruturação de dados.
- Organizar informações utilizando diferentes representações.
- Demonstrar como listas, grafos e hierarquias funcionam.
- Desenvolver pensamento computacional aplicado.

---

# 💡 Tema Escolhido

## FoodConnect

Sistema inteligente de delivery e gestão de restaurantes.

O projeto representa:

- Usuários
- Restaurantes
- Pedidos
- Entregadores
- Categorias de alimentos

---

# 🧠 Estruturas Aplicadas

## 🔹 Lista
Representação sequencial dos pedidos realizados.

## 🔹 Grafo
Representação das conexões entre clientes, restaurantes e entregadores.

## 🔹 Hierarquia
Representação da estrutura organizacional do sistema.
