# 🍔 FoodConnect – Tratamento de Erros e Avaliação de Soluções

## 📖 Descrição

Este projeto foi desenvolvido na disciplina de Pensamento Computacional, no curso de ADS.

A atividade tem como objetivo aplicar o tratamento de erros no projeto FoodConnect, identificando problemas de sintaxe, lógica e execução, corrigindo-os e avaliando a qualidade da solução final.

---

## 🎯 Objetivos da Atividade

- Identificar erros presentes no projeto.
- Classificar os erros como sintaxe, lógica ou execução.
- Corrigir os erros encontrados.
- Justificar as alterações realizadas.
- Avaliar a solução final quanto à clareza, eficiência e escalabilidade.

---

## 💡 Sistema Trabalhado

O sistema FoodConnect é uma aplicação simples de delivery, contendo:

- Tela de login
- Cardápio
- Realização de pedidos
- Rastreamento de entrega
- Backend básico com Node.js
- Banco de dados MySQL
